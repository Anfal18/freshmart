# 🛒 FreshMart – Online Grocery Shopping Website

FreshMart is a responsive online grocery shopping website built with React, JavaScript, HTML, and CSS. It allows users to browse fresh fruits and vegetables, search products, manage their shopping cart, proceed to checkout, and generate printable bills through a user-friendly interface with smooth animations and a green-themed design.
